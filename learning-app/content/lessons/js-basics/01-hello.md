# プログラムを動かしてみよう

プログラムとは、コンピューターへの「指示書」です。このレッスンでは、JavaScript で最初のプログラムを動かします。

## JavaScript はどこで動く？

JavaScript は、Chrome や Edge などの**ブラウザの中で動く**プログラミング言語です。特別なソフトをインストールしなくても始められます。

## 最初のプログラム

ブラウザで `F12` キーを押すと「開発者ツール」が開きます。「Console（コンソール）」タブを選び、次の 1 行を入力して Enter を押してください。

```js
console.log("こんにちは、JavaScript！");
```

コンソールに `こんにちは、JavaScript！` と表示されれば成功です。

- `console.log(...)` は、かっこの中身を画面（コンソール）に表示する命令です。
- 文字は `"`（ダブルクォーテーション）で囲みます。囲んだ文字のまとまりを**文字列**と呼びます。

## 計算もできる

```js
console.log(3 + 4);   // 7
console.log(10 * 2);  // 20
```

`//` から後ろは**コメント**で、プログラムとしては実行されません。メモを書くのに使います。

## まとめ

- JavaScript はブラウザで動く
- `console.log()` で結果を表示できる
- 文字列は `"` で囲む、`//` はコメント
