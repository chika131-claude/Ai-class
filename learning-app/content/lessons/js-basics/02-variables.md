# 変数とデータの種類

**変数**は、データに名前をつけてしまっておく「箱」です。

## 変数をつくる

```js
let name = "さくら";
let age = 20;
console.log(name + "さんは" + age + "歳です");
```

- `let` で変数をつくります。`=` は「右の値を左の箱に入れる」という意味です（数学の「等しい」ではありません）。
- `let` でつくった変数は、あとから中身を入れ替えられます。

```js
let score = 50;
score = 80;        // 中身を 80 に入れ替え
console.log(score); // 80
```

## 変わらない値は const

中身を変える予定がない値は `const` を使います。うっかり書き換えるとエラーになるので、ミスを防げます。

```js
const TAX_RATE = 0.1;
```

## データの種類（型）

| 種類 | 例 | 説明 |
| --- | --- | --- |
| 数値 (number) | `42`, `3.14` | 計算に使える |
| 文字列 (string) | `"りんご"` | 文字のまとまり |
| 真偽値 (boolean) | `true`, `false` | はい / いいえ |

`typeof` で種類を調べられます。

```js
console.log(typeof 42);      // "number"
console.log(typeof "42");    // "string"
```

`"42"` は見た目は数字でも**文字列**です。`"42" + 1` は `"421"` になるので注意しましょう。

## まとめ

- 変数は `let`、変えない値は `const`
- 数値・文字列・真偽値などの種類がある
