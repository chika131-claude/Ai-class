# 条件分岐 if 文

「もし〜なら、〜する」という処理を書くのが **if 文** です。

## 基本の形

```js
let score = 75;

if (score >= 60) {
  console.log("合格です");
} else {
  console.log("もう少し！");
}
```

- `( )` の中に条件を書きます。条件が `true` なら `{ }` の中が実行されます。
- `else` は「そうでなければ」です。

## 比較の記号

| 記号 | 意味 |
| --- | --- |
| `===` | 等しい |
| `!==` | 等しくない |
| `>` / `<` | より大きい / より小さい |
| `>=` / `<=` | 以上 / 以下 |

等しいかどうかは `==` ではなく **`===`** を使うのがおすすめです。`==` は `"5" == 5` が `true` になるなど、型を勝手に変換してしまうためです。

## 3 つ以上に分ける

```js
if (score >= 80) {
  console.log("A");
} else if (score >= 60) {
  console.log("B");
} else {
  console.log("C");
}
```

上から順に調べ、最初に当てはまったところだけが実行されます。

## まとめ

- `if (条件) { ... } else { ... }`
- 等しいかは `===` で比べる
- `else if` で 3 つ以上に分けられる
